
# App_chambaExpress - Bot Studios

Aplicación móvil desarrollada con Flutter y Firebase.

ChambaExpress conecta a clientes que necesitan servicios para el hogar con trabajadores que ofrecen sus servicios.

## Tecnologías
- Flutter
- Dart
- Firebase Authentication
- Cloud Firestore

## Funcionalidades en desarrollo
- Registro e inicio de sesión.
- Roles de cliente y trabajador.
- Catálogo de categorías de servicios.
